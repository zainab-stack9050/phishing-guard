# Smart Phishing Guard

An on-device Chrome extension designed to provide explainable phishing detection by analyzing webpage indicators and alerting users with human-readable security feedback.

### 📊 Project Status: Phase 0 (Scaffolding & Architecture)
*This project is actively in development. The current focus is setting up the baseline system communication, repository structure, and dependency environments.*

## 🚀 Key Features (Planned)
* **On-Device Analytics:** Evaluating page metadata locally to prioritize user privacy.
* **Explainable Alerts:** Moving beyond generic block screens by detailing *why* a site triggered a flag.
* **Lightweight Heuristics:** Processing URL patterns and structural elements efficiently.

## 🛠️ Tech Stack
* **Frontend:** Chrome Extension API (JavaScript, HTML, CSS)
* **Backend Core:** Python (Data cleaning and feature extraction scripts)
